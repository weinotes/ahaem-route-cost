# Backlink and distribution program

Last reviewed: 2026-11-14

## Principle

The calculator must be useful without the CTA. A self-owned GitHub Pages link to
AHAEM or CEXAH is not a substitute for earned editorial links. The public tool
must attract independent links, directory listings, tutorials, repository stars,
forks and embedded use.

Do not:

- publish a full mirror of either commercial website;
- bulk-submit to low-quality directories;
- automate account creation, comments, direct messages or email blasts;
- hide the relationship to AHAEM;
- promise rankings, returns or guaranteed link placement;
- add affiliate parameters to this public repository.

## Why this asset matters

The page provides an independently useful task: calculating true transfer cost
from user-provided fixed and percentage inputs. It then sends users to:

- AHAEM when they need network, wallet and multi-step route planning;
- CEXAH when they need exchange and trading-cost research.

Both destinations serve a different intent, so the page does not need to force
both brands into the same CTA.

## Publication order

1. Verify the deployed page, canonical URL and sitemap.
2. Add repository description, homepage and relevant topics.
3. Submit only to directories where the tool is a genuine fit.
4. Publish one technical article explaining the model and privacy design.
5. Contact 10 highly relevant creators/resource owners with individualized copy.
6. Wait for replies and record outcomes in `backlink-prospects.csv`.
7. Re-check every earned link monthly for status, placement and link attribute.

## Measurement

For AHAEM:

- Google Search Console links and query/page reports;
- Bing Webmaster Tools backlinks;
- referral traffic and planner CTA clicks;
- branded search demand.

For CEXAH:

- Google Search Console and Bing Webmaster Tools;
- GTM referral and tool events;
- exchange comparison and calculator sessions;
- partner/referral conversion only after consent and regional checks.

Do not add third-party analytics to this calculator without updating the page
privacy copy and validating consent requirements.

## Outreach rules

- Maximum one initial email and two follow-ups.
- No more than one relevant destination from this page per message.
- Identify AHAEM affiliation.
- Explain why the target page is relevant.
- Offer the formula and source repository, not only a request for a link.
- Stop immediately after a decline.

## Initial targets

1. Pages that teach exchange withdrawal fees but lack a downloadable formula.
2. Wallet security/resource pages explaining transfer risk.
3. Crypto card cost explainers that ignore funding and spread costs.
4. Open-source directories for browser-based financial calculators.
5. CEXAH exchange-cost articles that can cite the open calculator as a supporting
   tool where the content genuinely benefits.
